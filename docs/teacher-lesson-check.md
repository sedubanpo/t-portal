# 강사 수업 체크 컴포넌트

`portal-reminder.js`와 `portal-reminder.css`가 구현하는 강사 전용 달력 카드다. 기존 포털의 흰색·파란색과 Pretendard를 유지하며, 수업 후 시수 동의와 수업일지 제출 상태를 각각 확인한다. 제품 권한과 데이터 소유권은 루트 `PRODUCT.md`를 따른다.

## 표시와 상태

- 인증된 일반 강사에게만 표시한다. 관리자와 읽기 전용 실무자는 대상에서 제외한다.
- 한국 시간 기준 이번 달과 지난달을 조회한다. 인트라넷에서 전송된 실제 수업 중 오늘까지의 날짜이며 수업 시간이 양수인 기록만 상태를 표시한다. 미래 날짜에는 미완료 경고를 만들지 않는다.
- 날짜마다 `시`(시수 동의)와 `일`(일지 제출)을 구분한다. `✓ 완료`는 녹색, `! 필요`는 황색, `? 확인 필요`는 회색이며 기호와 설명을 함께 제공한다.
- 일지 연결을 확인할 수 없거나 시수 동의 정보가 없으면 `확인 필요`로 표시한다. 알 수 없는 상태를 미완료 건수에 포함하지 않는다. 같은 날 일지 상태가 섞이면 확인 불가 상태가 우선한다.
- 로딩, 조회 실패, 실제 수업 없음, 모두 완료를 별도 문구로 안내한다. 새로고침으로 다시 조회할 수 있다.

## 동작과 연결

`portal-home.js`가 `maybeShowPortalLessonCheck()`를 호출한다. `lesson-log-editor.js`의 `readPortalLessonCheck()`로 수업·일지 연결 상태를 읽고, 기존 시수 대시보드 응답으로 날짜별 동의 상태를 읽는다. 날짜 선택 후 **시수 확인** 또는 **일지 확인**을 누르면 해당 날짜의 기존 화면으로 이동한다. 계정 또는 조회 월이 바뀐 뒤 도착한 이전 요청 결과는 반영하지 않는다.

닫기와 Escape는 카드를 접고 **수업 체크** 버튼을 남긴다. 일반 닫기는 현재 페이지 수명 동안 유지된다. **24시간 동안 안 보기**를 체크한 뒤 닫으면 만료 시각을 UID별 `localStorage` 키 `portal.lesson-check.snooze.v1:<uid>`에 저장한다. 이 설정은 같은 브라우저의 해당 계정에만 적용되며, 접힌 버튼으로 언제든 다시 열 수 있다. 저장소 사용이 차단되면 닫기는 동작하지만 다음 방문까지 숨김을 보장하지 않는다.

## 모양과 반응형 규칙

- 화면 오른쪽 아래의 비모달 흰색 카드다. 배경 차단이나 포커스 가두기를 추가하지 않는다. 기본 너비는 352px, 모서리는 24px이며 파란색 `#2563eb`를 선택·포커스 강조에 사용한다.
- 767px 이하에서는 너비 336px, 화면 가장자리 여백 12px, 최대 높이 65dvh를 사용한다. 화면 너비에 맞춰 더 줄어들며 하단 안전 영역을 반영한다.
- 제목, 월 이동, 닫기와 숨김 설정은 유지하고 달력·상세 본문만 세로로 스크롤한다. 그림자는 `0 12px 42px #203f6826`이다.
- 날짜 버튼의 접근성 이름에 수업 건수와 두 상태를 함께 넣고, 선택 여부는 `aria-pressed`로 제공한다. 키보드 포커스는 3px 파란 외곽선으로 표시한다. 움직임 감소 설정에서는 등장 애니메이션을 끈다.

## 확인 범위

합성 데이터로 독립 컴포넌트를 검토한 범위다. 데스크톱·모바일 캡처는 `/private/tmp/portal-calendar-review/desktop.png`, `/private/tmp/portal-calendar-review/mobile.png`에 있으며, 기존 검증 로그는 `/private/tmp/portal-v558-tests.log`에 있다. 이 자료만으로 실제 운영 계정의 인증·데이터 연결이나 배포 완료를 주장하지 않는다. 임시 경로의 자료는 장기 보관용이 아니다.
