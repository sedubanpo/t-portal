# v536 · 주간 비교와 본문형 업무 화면

## 기준

- 승인된 파란색·흰색 PC/모바일 시안을 유지하는 Operate UI 보완.
- KPI 큰 숫자는 선택 월 누계. 증감은 선택 월의 최신 등록 수업일을 포함한 7일과 그 직전 7일을 비교한다. 연도·월 경계를 넘어도 7일씩 집계한다. 실제 인정 시수가 있는 수업만 건수에 포함한다.
- 지난 수업의 동의 표시는 수업별 별도 서명이 아니라 해당 강사·날짜의 동의 상태다. 기존 날짜 단위 안내를 유지한다.
- 공지 제목이나 중요 여부를 만들어내지 않는다. S-LMS 원문을 두 줄 요약 영역에 표시하고 펼쳐 읽는다. 날짜는 원본 업데이트 날짜다.
- 페이지 어댑터는 주 업무 화면만 대상으로 한다. 원래 조회·권한 검사·종료 함수를 유지하며, 확인·수정·상세 팝업과 외부 링크는 변경하지 않는다.
- PC/모바일 보기 전환은 역할과 무관하며 모바일 상단에 복귀 버튼을 둔다. 실제 휴대폰에서 PC 보기 선택 시 가로 스크롤을 허용한다.

## 확인

- 오프라인 회귀 35개, 홈 데이터·시수 세션·변경 이력 단위 검사.
- 연도 경계, 14일 바깥 데이터, 취소 수업 제외, 정수/소수 시간 표기 검사 추가.
- 합성 강사 화면에서 PC·모바일 미리보기·390px 화면 및 본문형 시수 조회 확인. 1차 점검에서 기존 모바일 CSS가 시간 카드를 숨기는 문제를 발견하여 보완.
- 변경 작업은 프런트엔드만 포함한다. 권한 정책과 실제 시수/서명 데이터는 변경하지 않는다.
- 운영 v536에서 송경석 9월 월 누계 133건/329시간 유지, 9/14–20 48건/119시간 대 9/7–13 46건/115시간으로 +2건/+4시간 확인.
- 본문형 시수 조회의 학생 명단 길이가 달력을 늘리지 않도록 날짜 셀 높이와 명단 스크롤 영역을 분리했다.
