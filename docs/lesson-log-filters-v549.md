# v549 수업일지 필터와 관리자 조회

## 변경

- 수업일지 제출의 상태 드롭다운을 전체/작성 중/전송 중/제출 완료/확인 필요/보관의 6개 색상·아이콘 버튼으로 교체. `aria-pressed`로 선택 상태 표시.
- 작성·Fillout 버튼의 높이와 정렬 통일. 기존 PC 5열 규칙이 10열 일지 목록을 덮어쓰던 CSS 우선순위 수정. 헤더와 행의 실제 grid 열을 동일하게 확인.
- 관리자 전용 공통 강사 선택 dialog: 인물 아이콘, 국어·영어·수학·과학·사회·기타 그룹, 이름/과목 검색, 현재 선택 표시. 실제 프로필 과목을 사용하며 이름으로 과목을 추정하지 않음. 과목 미등록은 기타에 표시.
- 수업일지 제출/나의 현황/지난 수업일지/미작성 수업/미전송 관리에서 공통 선택기를 사용.
- 관리자의 지난 수업일지와 미작성 수업은 처음에 전체 강사로 조회. 명시적으로 선택한 범위는 탭별 유지. 나의 현황은 선택 강사를 조회하며 다른 탭의 기본 범위에 영향을 주지 않음.
- 일반 강사에게 강사 선택 UI/명단을 제공하지 않으며 서버는 본인 범위 강제. 조회 대상 변경은 대리 작성/제출 권한을 부여하지 않음.
- Escape·닫기 버튼·바깥 영역으로 닫기, 기본 dialog의 키보드 초점 관리, 선택 후 트리거로 초점 복원. 강사 선택 시 입력한 조회 기간 보존.

## 검증 (2026-09-30 KST)

- 관련 자동 테스트 58개 통과. 관리자 전체/선택 조회, 일반 강사 foreign UID 무시, 과목 그룹/검색/중복 UID 제거, 관리자 전용 과목 정보, 기존 전송 복구 회귀 포함.
- 가상 데이터 브라우저: 상태 필터 선택, 과목 검색, 수학 강사 현황 선택, history/missing 전체 기본값, overview 선택 보존, 일반 강사 선택기 없음, Escape 후 초점 복귀, 날짜 입력 유지.
- 1440×960 PC와 390×844 모바일 캡처. 헤더/행 10열 grid 계산값 동일. 모바일 dialog 가로 넘침 없음.
- 운영 읽기 전용 검증: 과목 정보 분포 확인. 2026-09-01~30 관리자 전체 조회는 1,831개 수업과 1,084개 지난 일지 반환. 시점성 수치이며 현재 건수로 고정하지 않음.
- Impeccable detector: findings 없음. 독립 화면 검토 SHIP. 실제 iPhone 키보드·Safari 검증은 수행하지 않음.
