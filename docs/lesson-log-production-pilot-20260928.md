# 운영 수업일지 1인 파일럿 — 2026-09-28

사용자 승인에 따라 운영 준비와 안준성 계정만의 제출을 활성화했다.

- 운영 Notion 데이터 소스에 `Portal draft ID` rich_text 속성 추가. 기존 일지 본문과 수강 배정은 변경하지 않았다.
- 기존 Fillout 강사 페이지 ID 및 확정된 학생 공개 Notion 연결을 대조하여 강사 30명, 학생 119명 매핑 저장. 중복 대상 0건. 대조되지 않은 강사 2명과 학생 3명은 자동 연결하지 않았다.
- 운영 스키마 preflight 및 안준성·박성민 매핑 검증 통과.
- runtime은 `enabled: true`, `pilotUids`는 안준성 한 명, `environment: production-pilot`. 테스트 fixture는 제거했다.
- 공개 기본 진입은 Fillout 유지. 새 작성 화면은 `https://sedubanpo.github.io/t-portal/?lesson_log_pilot=1`로 진입하며 서버에서 계정을 제한한다.
- 학생 선택은 담당 여부와 관계없이 활성 학생의 최소 정보만 제공한다. 타인 초안 수정·대리 제출은 허용하지 않는다. 연결 미확정 학생의 최종 제출은 차단하며 초안은 보존한다.
- 새 초안 생성 시 전송 대상을 고정한다. 환경이 바뀐 초안의 제출을 차단하고, worker는 현재 설정 대신 제출 당시 고정 대상을 사용한다. 대상 정보 없는 이전 대기 건은 검토 상태로 보존한다.

## 운영 및 되돌리기 절차

안준성 계정은 새 주소에서 새 일지를 작성한다. 테스트에서 만든 초안을 운영 제출용으로 재사용하지 않는다. 다른 계정은 기존 Fillout을 사용한다.

문제 발생 시 runtime의 `enabled`를 false로 하고 `verificationUids`를 빈 배열로 유지하여 새 기능을 중단한다. 기존 Fillout과 원본 초안은 보존한다. Notion 속성·매핑·일지를 삭제하지 않는다. 전체 계정 확대는 별도 승인 후 진행한다.
