# 관리자 운영 UI 변경 기록 — v551

## Overview

실제 계정의 사람을 빨리 찾고 재원생 학교 조건을 손쉽게 조합하는 운영 화면이다. 이번 기록은 관리자 강사 선택과 재원생 통계 필터의 완료된 구현에 한정한다. 프로젝트 전체 디자인 시스템을 재정의하지 않는다.

구현 근거는 강사 포털의 `portal-admin-ui.css`, `portal-admin-ui.js`, `index.html`이다. 기존 `DESIGN.md`는 읽기만 했으며, 이 문서로 대체하지 않았다. 서버 변경은 없다.

## Colors

기존 흰색·블루 업무 화면을 유지한다. 선택과 적용은 블루 (`#2563eb`), 선택 면은 옅은 블루 (`#eff6ff`), 강조 글자는 진한 블루 (`#1d4ed8`)다. 흰색 대화상자와 중립 경계가 항목을 구분하며, 포커스는 블루 윤곽선으로 표시된다. 이는 이번 컴포넌트의 실제 CSS 값이며 새 전역 토큰을 정의한 것은 아니다.

## Typography

Pretendard, sans-serif와 Material Icons Round를 유지한다. 대화상자 제목은 데스크톱 23px·모바일 21px, 강사 이름은 15px, 검색 입력은 14px, 보조 정보와 선택지 설명은 12–13px로 구현되어 있다. 이름과 과목은 줄바꿈할 수 있어 긴 텍스트가 카드 폭을 밀어내지 않는다.

## Layout

강사 목록은 과목별로 묶고 각 묶음 안에서 이름순으로 표시한다. 기본 3열, 767px 이하 2열, 370px 이하 1열이다. 따라서 390px 모바일 검증 화면은 2열이다. 목록 영역만 스크롤하고 검색·과목 선택·닫기 영역은 대화상자 안에 남는다.

통계 상세 필터는 기본 4열, 모바일 2열이며 모바일에서는 펼치기 버튼으로 노출한다. 학교 선택지는 기본 2열, 모바일 1열이다. 선택지·적용·취소는 최소 높이 44px이고, 모바일에서는 과목 선택·학교 선택 해제·정렬도 44px로 구현되어 있다. 닫기 아이콘 버튼은 현재 40px이므로 모든 조작이 44px라는 계약으로 확대하지 않는다.

## Elevation & Depth

native `dialog.showModal()`과 반투명 backdrop으로 현재 작업에 집중시킨다. 흰색 대화상자에 그림자를 적용하고, 내부 항목은 얇은 경계와 선택 색으로 구분한다. 강사 카드의 배경·경계 전환은 0.16초이며 reduced motion 설정에서는 제거된다.

## Shapes

대화상자는 둥근 모서리 (16px), 강사 항목은 둥근 카드 (12px), 프로필은 원형으로 구현되어 있다. 입력·선택지·버튼의 모서리 값은 해당 컴포넌트 CSS에 남겨 두며 전역 모서리 체계로 승격하지 않는다.

## Components

### 강사 선택

- 실제 계정의 이름·과목·프로필 사진을 사용한다. 국어·영어·수학·과학·사회·기타 묶음, 과목별 인원과 검색 결과 인원을 표시한다.
- 이름·과목 검색은 NFKC 정규화 후 공백과 대소문자 차이를 제거한다. 과목 선택과 검색을 함께 적용한다.
- 사진은 HTTP(S) 주소만 허용하고 GitHub 파일 주소는 raw 주소로 정리한다. 사진이 없거나 로드가 실패하면 기본 Material `person`이 남는다. 이름·과목은 사진과 독립적으로 읽힌다.
- 현재 조회 강사는 선택 상태로 표시한다. 강사를 누르면 대화상자를 닫고 기존 강사 조회 전환 흐름을 실행한다.
- 열 때 검색에 포커스를 두며, 닫기·Escape·바깥 영역 클릭 후 열었던 조작으로 포커스를 복원한다.

### 재원생 필터와 정렬

- 담당 강사·과목·학교급·학교·학년·출석 상태·수업 횟수·정보 확인은 검색 가능한 선택 대화상자로 조작한다. 기존 select는 선택 상태의 원본으로 남는다.
- 학교는 여러 곳을 선택할 수 있다. 대화상자의 임시 선택은 적용해야 반영되고, 취소·닫기·Escape는 적용 전 변경을 버린다. 단일 선택 필터는 항목을 누르면 즉시 적용한다.
- 학교 인원은 선택 월의 전체 통계 행 기준이다. 다른 필터를 적용한 결과의 인원으로 해석하지 않는다. 학교를 초등·중등·고등·기타로 묶고, 선택 월에 없는 기존 선택도 0명으로 남긴다.
- 여러 학교는 OR 조건이고, 다른 필터와는 AND 조건이다. 정보 확인의 학교/학년 없음은 빈 값·공백·`-`·`확인필요`·`정보없음`을 찾는다.
- 정렬은 수업 많은 순·이름순·학교 및 학년순·최근 수업순이다. 동률은 이름순으로 정리하고 학년 비교에는 숫자 비교를 사용한다.
- 적용한 학교는 학교마다 해제할 수 있는 칩으로 표시한다. 필터 적용은 첫 페이지로 이동하며, 필터와 정렬 변경 자체는 학생 체크 선택을 지우지 않는다.
- 선택지 재구성 시 기존 필터 값을 유지한다. 월 변경 등 데이터 재적재에서는 기존 학생 체크 선택을 초기화하므로 월을 넘는 체크 선택 보존을 보장하지 않는다.
- 전체 초기화는 필터·검색·수업형태·학생 체크 선택을 해제하고 기본 정렬과 첫 페이지로 돌아간다. 검색 결과 없음과 선택 월 데이터 없음은 각각 안내한다.

### 검증과 한계

2026-10-01 검증: 테스트 14개 통과, 최종 reviewer의 ship 판정 완료. PC 1440px·모바일 390px·넓은 화면 2048px에서 강사 선택과 통계 화면을 확인했으며 실제 프로필 사진 16개 로드 성공을 관측했다. 화면 검증에는 `scripts/build-admin-ui-preview.cjs`로 생성한 독립 로컬 미리보기를 사용했다.

통계 화면과 학교 조합 검증에는 synthetic 학생 fixture만 사용했다. 실제 학생 데이터에 대한 운영 검증이나 실제 iPhone 기기 검증은 아니다. 이 문서 작성 과정에서는 코드를 읽었으며 테스트나 브라우저 검증을 재실행하지 않았다.

## Do's and Don'ts

이번 변경을 유지보수할 때 선택 월 기준 인원, 학교 선택의 적용·취소, 사진 실패 대체, 필터 값 보존 범위를 함께 유지한다. 이번 대화상자의 너비·모서리·글자 크기·그림자를 프로젝트 전역 규칙으로 만들지 않는다. 기존 `DESIGN.md`와 `.impeccable/design.json`은 이번 기록에서 수정하지 않았다.

검증 재현: `node --test scripts/test-portal-admin-ui.cjs scripts/test-portal-home.cjs scripts/test-lesson-log-client.cjs`. 가상 화면 생성: `node scripts/build-admin-ui-preview.cjs /tmp/portal-admin-preview`. 생성 폴더를 로컬 HTTP 서버로 제공해 확인한다. 기본 미리보기는 가상 강사·학생만 사용하며 실제 계정 사진을 포함하지 않는다.
