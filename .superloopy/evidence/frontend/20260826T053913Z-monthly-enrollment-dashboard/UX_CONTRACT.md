# 월별 재원 통계 UX 계약

- 대상: 강사 포털 관리자 계정의 수강생 통합 관리.
- 목적: 월별 활성 재원생 규모와 신규·활성 해제 흐름을 한 화면에서 빠르게 파악한다.
- 활성 재원생: 선택 월에 결석·취소·예고가 아니며 인정 시수가 0보다 큰 수업이 1회 이상 있는 고유 학생.
- 신규 활성: 선택 월에는 활성이며 직전 12개월 관측 범위에는 활성 이력이 없는 학생. 관측 월이 누락되면 `추정`으로 표시한다.
- 활성 해제: 전월에는 활성이었으나 선택 월에는 인정 시수가 없는 학생. 퇴원 확정이 아니라 중지·퇴원 후보로 표시한다.
- 진행 중인 달: 남은 수업이 존재하므로 활성 해제 수치를 잠정치로 명시한다.
- 강사별 통계: 학생-강사 연결 기준. 복수 강사 수강생은 각 강사에 각각 포함되며 화면에 이 중복 기준을 명시한다.
- 장애 처리: 일부 월 조회 실패 시 성공한 월을 표시하고 누락 월을 알린다. 선택 월 실패 시 재시도 화면을 표시하며 기존 데이터를 변경하지 않는다.
- 접근 제어: 기존 관리자 전용 월간 학생 요약 권한을 재사용하며 일반 강사와 익명 사용자의 전체 학생 조회 권한은 추가하지 않는다.
