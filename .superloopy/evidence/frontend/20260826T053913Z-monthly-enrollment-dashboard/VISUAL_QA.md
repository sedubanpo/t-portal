# Visual QA

## 대상

- 실제 `index.html`의 월별 재원 통계 모달을 Chromium에서 렌더링했다.
- 화면 데이터만 식별 정보가 없는 합성 데이터로 주입했다. 레이아웃·CSS·렌더 함수는 배포 소스와 동일하다.

## 결과

| 화면 | 뷰포트 | 결과 |
| --- | --- | --- |
| `desktop-1440x1000.png` | 1440 × 1000 | KPI 4개, 12개월 추이, 상태 전환, 강사별 표가 겹침 없이 표시됨 |
| `mobile-390x844.png` | 390 × 844 | KPI가 2열로 재배치되고 차트·강사 표는 내부 가로 탐색, 전체 모달은 세로 탐색 가능 |

## 확인 사항

- 데스크톱 모달 폭 1397px, 콘텐츠 폭 1346px. 모달 자체의 불필요한 가로 오버플로 없음.
- 모바일 모달 폭 390px, 콘텐츠 폭 366px. 소메뉴는 기존 패턴대로 가로 스크롤 가능.
- 숫자에는 tabular 숫자 정렬을 적용했고 신규/활성 해제는 색상만이 아니라 제목과 숫자로 함께 구분했다.
- 진행 중인 달의 활성 해제 수치에는 잠정치 경고문을 함께 표시했다.
